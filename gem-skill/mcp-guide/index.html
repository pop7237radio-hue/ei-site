— Claude Code × Gemini Notebook 接続の1枚

GemのSkills化（GPS）事前登録特典／2026-08-17版（全コマンド実測済み）

Gemの知識に入れたGemini Notebook（旧NotebookLM）、名前しか見えずに諦めていませんか。
この1枚の手順で、Claude CodeがNotebookの中身（PDF・スプシ・全ソース）まで読めるようになります。

手順（4ステップ・所要5分）

STEP 1: インストール（コピペ2行）
python3 -m venv ~/.notebooklm-mcp/venv
~/.notebooklm-mcp/venv/bin/pip install notebooklm-mcp-cli
STEP 2: ログイン（ブラウザが開く→自分でGoogleログイン）
~/.notebooklm-mcp/venv/bin/nlm login

※パスワードはAIに渡しません。自分のブラウザで普通にログインするだけです。

STEP 3: 確認
~/.notebooklm-mcp/venv/bin/nlm login --check
「Authentication valid! / Notebooks found: ◯◯」が出たら成功
STEP 4: Claude Codeに登録（フルパスがコツ・つまずきポイント）
claude mcp add --scope user gemini-notebook-mcp ~/.notebooklm-mcp/venv/bin/notebooklm-mcp
claude mcp list
「✓ Connected」が出たら完成。次に開いたClaude CodeからNotebookが読めます

つまずきは1点だけ

公式の nlm setup add claude-code は「✗ Failed to connect」になることがあります（コマンドの場所が伝わらないため）。上のSTEP 4のフルパス登録なら一発です。——これ、私も最初に踏みました。

注意書き（必ず読んでください）

  • 非公式ツール（notebooklm-mcp-cli・MITライセンス）です。Google公式サポート外で、仕様変更により予告なく動かなくなる可能性があります
  • Cookie認証方式のため、ログイン情報がPC内に保存されます。共有PCでは使わないでください
  • 顧客情報・医療情報・機密を含むNotebookには接続しないでください。読み取り専用で使うのが安全です
