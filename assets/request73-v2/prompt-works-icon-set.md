## 透過修正履歴

初回3点は見た目上のチェッカーをRGBAの透明表示と誤認させるRGB画像だったため不採用。各画像をedit targetとして、前景を維持し「背景の灰白チェッカーだけを実alphaへ置換」する`background-extraction`をbuilt-in imagegenで個別実行した。

- Keep unchanged: 被写体、個数、顔、ポーズ、色、質感、構図、光、接地影
- Change only: 灰白チェッカー背景 → alpha 0
- Recheck: `opaque=False`、alpha min/max、3背景、64px、4辺余白
- `learning-hint`は最初の透過修正2回もRGBだったため不採用。3回目の前景cutoutで実alphaを得た
- imagegen透過原本は`original/*-transparent-original.png`へ保存。`selected/`はその原本を1254×1254の透明キャンバスへresampleし、4辺10%以上を確保した候補でありnative生成とは呼ばない
