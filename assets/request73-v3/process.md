# 依頼書73-v3 制作記録

## なぜ／何が

なぜ小さく見えたか: 1254角の透明キャンバス内に保護余白があり、その正方形全体を小さな固定枠へ`contain`していたため、透明余白とCSS枠で二重に縮小されていた。

何を直したか: 採用原本を残したまま、実画の外側へ約4%だけ残すtight派生WebPを作り、CSSのpaddingを0にして表示枠自体も拡大した。

## 非破壊の派生処理

| 用途 | 原本からのcrop | 配信用寸法 |
|---|---:|---:|
| 美容室 | `1017x574+121+332` | 640×361 |
| 行事・持ち物 | `1037x468+127+409` | 640×289 |
| 学習ヒント | `984x948+155+148` | 640×617 |
| 学校相談 | `915x828+154+207` | 640×579 |
| 記録・見守り | `997x680+148+275` | 640×437 |
| 診断ツール | `954x699+164+222` | 640×469 |

- 元の`original/`・`selected/`・v2配信用画像は上書きしていない。
- 新規生成ではなく、採用済みimagegen画像の透明余白だけを機械的に整理した。
- Brain商品2件は概念アイコンを作らず、実際の商品画像を720×377 WebPへ軽量化して使用した。
